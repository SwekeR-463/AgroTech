# AgroTech

**Crop Recommendation and Yield Prediction System**

A machine learning-based system to assist farmers in making informed decisions. 

**Key Features:**

* **Crop Recommendation:** Suggests suitable crops based on climate and soil conditions.
* **Yield Prediction:** Forecasts potential yield using historical data and real-time information.

**How it works:**

1. **Data Collection:** Gather historical weather, soil, and crop yield data.
2. **Model Training:** Train machine learning models for recommendation and prediction.
3. **User Input:** Users provide location, soil type, and desired crop.
4. **Prediction and Recommendation:** System generates tailored suggestions and forecasts.

**Technical Stack:**

* Python
* Pandas
* NumPy
* Scikit-learn<br>
Flask code for the [Yield Predictor](https://github.com/SwekeR-463/Yield-Predictor) & [Crop Recommender](https://github.com/SwekeR-463/Crop-Recommender)
